#   - a new name starting with "$" is a simple name for a nested class; the outer class
#     is taken from the InnerClasses attribute, so the result is <mapped outer>$<simple>
#   - a trailing "?" marks a name inferred with low confidence (review these first)

#   - modules (subclasses of Module) from the name string passed to the Module constructor,
#     placed in client/onyx/module/<category>/
#   - nested setting groups from their group label (+ "Settings")
#   - everything else gets a placeholder (Class_<n>) and is reported
